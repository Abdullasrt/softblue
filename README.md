# SoftBlue Premium Tea — Single-Origin Munnar (1,600m)

> *"Unveil Purity. Sky's the Limit"*

A luxury, storytelling-driven e-commerce platform built for **SoftBlue Premium Tea** using **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Key Features

- **Hero & Dawn Ritual Showcase**: Animated snow-capped Munnar mountain mist hero card with 5:00 AM predawn plucking ritual narrative.
- **World's Rarest Teas Grid & Lore Modals**: Luxury cards featuring 6 rare teas (*Da Hong Pao, Yellow Gold Tea Buds, Manohari Gold, Makaibari Silver Tips Imperial, Gyokuro, Nilgiri Frost*) with deep history modals.
- **The Munnar Story**: Visual storytelling cards detailing Munnar’s 1,600m high-altitude terroir and 100% single-estate purity guarantees.
- **Interactive Product Showcase & Pouch Switcher**: Interactive switcher for front packaging view (`pouch-front.png`) and back nutritional information (`pouch-back.png`), 4 special bundle offers, and interactive cart drawer.
- **Verified Connoisseur Reviews Slideshow**: Responsive Framer Motion review slideshow carousel with dots pagination and "Write a Review" modal.
- **Dedicated Contact & HQ Concierge**: Office location (*KC Arcade, CSEZ PO, Kakkanad, Kochi, Kerala*), official WhatsApp concierge SVG link (`+91 90720 01441`), and direct inquiry form.
- **Vercel & GitHub Ready**: Pre-configured with `vercel.json` SPA rewrites and clean Vite build pipeline.

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/your-username/softblue-tea.git
cd softblue-tea

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```

The production output will be generated in the `dist/` directory.

---

## ⚡ Deployment to Vercel

### Option 1: Vercel CLI
```bash
npx vercel
```

### Option 2: GitHub Integration
1. Push this project repository to **GitHub**.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository `softblue-tea`.
4. Vercel will automatically detect **Vite** settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**!
